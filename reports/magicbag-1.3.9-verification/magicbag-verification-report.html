Fixes shipped (user-facing)

# Fix Where Confirmed by this test
1 Rate labels vs priced service — checkout options could advertise the configured service (e.g. "USPS Priority") while the price came from a different service the API returned (e.g. Media Mail). Plans now carry the service_code of the rate that was actually priced; builders label from the API response, not settings. class-shipengine-service.php, class-shipstation-service.php YES — all 5 rendered options carried real carrier-service labels (screenshot 2).
2 ShipStation single-plan path priced the wrong service — it took the cheapest returned rate regardless of the requested service. request_rate() now filters to the requested service and the configured allow-list, and refuses to label a price the API did not confirm. class-shipstation-service.php YES — selecting USPS Priority charged exactly $14.51, the Priority price from the same rate set (screenshot 3).
3 Positional rate IDs — checkout IDs were sorted indexes; a re-sorted rate set could silently remap the customer's selection to a different service (select 2nd Day Air, pay Ground). IDs now derive from the service code + option content hash. class-shipping-method.php (build_rate_id()) YES — switching between rates updated the charged total to match the chosen option each time.
4 Mixed-carrier order plans — plans re-quoted every package against every enabled carrier (some bags UPS, some USPS), ignoring the service the customer paid for. Plugin::process_order() now captures the chosen service from the order's shipping-item meta, constrains planning to it, and warns when the plan total diverges from what was paid. class-plugin.php (process_order(), find_best_plan()) NOT TESTED — requires a placed order; see §6.
5 PirateShip CSV hardcoded "USPS / Priority Mail" — carrier and service columns now derive from the plan's actual service code. class-pirateship-export.php (derive_carrier_and_service()) NOT TESTED — requires a stored plan; see §6.
6 Generic fallback title removed — checkout options with no usable service label no longer fall back to the method title ("USPS Priority Optimizer" must never appear on a priced option). class-shipping-method.php (resolve_rate_title()) YES — no generic title appeared on any priced option.
